# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Interview Prep & Application Tracker** very seriously.

If you believe you have found a security vulnerability in this project, please **do not** open a public issue. Instead, report it privately:

1. **Email**: Send vulnerability details to `security@interviewtracker.dev` (or open a GitHub Private Vulnerability Advisory).
2. **Details to Include**:
   - Type of vulnerability (e.g. CSRF, SQL Injection, JWT bypass, SSRF).
   - Clear step-by-step instructions to reproduce the issue.
   - Proof-of-concept exploit script or payload if available.
   - Affected endpoints or components.

## Response SLA

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Patch**: Within 7 business days for high/critical vulnerabilities.
- **Public Disclosure**: Coordinated after a fix has been tested and deployed.
